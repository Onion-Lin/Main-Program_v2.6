# Main-Program — 蓝牙遥控小车 (STM32F103)

基于 **STM32F103** 主控的蓝牙串口遥控小车固件。通过 USART3（PC10/PC11）连接蓝牙串口模块（HC-05 / HC-06），接收手机 APP 发送的单字符指令控制小车前进/后退/转向/调速。

> **v2.6 原为电磁循迹版本，现已改造为蓝牙遥控版本。**

## 硬件接口

| 功能          | 外设         | 引脚                  |
|---------------|-------------|----------------------|
| 舵机转向       | TIM3_CH3    | PB0                  |
| 左轮 PWM      | TIM4_CH2    | PB7                  |
| 右轮 PWM      | TIM4_CH1    | PB6                  |
| 左轮方向       | GPIO        | PB8                  |
| 右轮方向       | GPIO        | PB9                  |
| 使能开关       | GPIO input  | PA12                 |
| 拨码开关 x4   | GPIO input  | PA8, PC8, PC9, PC7   |
| LED x4        | GPIO output | PA11, PA15, PC12, PB3|
| 蓝牙串口       | USART3      | PC10(TX) / PC11(RX)  |
| 调试串口       | USART1      | PA9(TX) / PA10(RX)   |

## 蓝牙遥控协议

小车通过 **USART3（115200-8N1）** 接收蓝牙模块数据，使用单字符命令：

| 命令 | 功能   | 说明                           |
|------|--------|-------------------------------|
| `W`  | 前进   | 直行前进                       |
| `S`  | 停车   | 电机停转                       |
| `A`  | 左转   | 前进 + 左转                     |
| `D`  | 右转   | 前进 + 右转                     |
| `X`  | 后退   | 直行后退                       |
| `+`  | 加速   | 基准速度 +50（上限 4000）        |
| `-`  | 减速   | 基准速度 -50（下限 100）         |

> 所有字母命令大小写均可识别。加速/减速时会通过蓝牙回传 `SPD+ ` / `SPD- ` 确认。

## 安全机制

- **使能开关（PA12）**：必须拨到 ON 位置才允许电机转动，OFF 时全部停止。
- **速度限幅**：左右轮速度限制在 ±4000 以内。
- **舵机限幅**：舵机输出限制在 ±85 以内（中值 792）。

## 拨码开关设定

4 位拨码开关用于设定蓝牙遥控的**基准速度**（`Std_Speed`）：

| 编码   | 基准速度 |
|--------|---------|
| 0000   | 550     |
| 0001   | 650     |
| 0010   | 650     |
| 0100   | 800     |
| 1000   | 1000    |

## 调试方式

- **VOFA+ 上位机**：通过 USART1 发送 Wheel_Left_Speed、Wheel_Right_Speed、Std_Speed、SteerPWM 共 6 通道 float 数据，配合 VOFA+ 实时波形监测。
